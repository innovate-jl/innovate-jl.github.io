# Unifolllow

Unifolllow compares Instagram export files directly in the visitor's browser. It is a static site; no build step or server-side upload is required.

## Run locally

From this folder, start Python's built-in web server:

```powershell
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## AdSense readiness

The home page retains the AdSense account loader and puts the checker, help, privacy, contact, terms, and FAQ within a clear site structure. Add manual ad units only after they are approved and have actual slot IDs. Keep ads separate from the file picker, compare button, and download button so they cannot be mistaken for site controls.

How to compare an Instagram export responsibly

A private, file-based approach to checking a snapshot—without a password or account connection.

By the Unifolllow editorial team · Last reviewed October 26, 2026

  • Learn More

Start with Instagram’s own files

Request your information from Instagram, unzip the archive, and find the follower and following files. For a clean comparison, select both files from the same download: followers_1.html with following.html, or the matching JSON files. Choosing files from different exports can mix two different moments in time.

Unifolllow compares the handles in those lists in your browser. It does not sign in to Instagram, fetch live profile data, or explain why a person followed or unfollowed.

  • Export first: Request your data directly from Instagram and choose an All time range when available.
  • Use one archive: Keep the selected follower and following files from the same download.
  • Keep the archive private: Do not email it to support or upload it to a public drive.

Interpret the result narrowly

The result is the set of accounts present in your following file but not in your followers file. It is useful for checking a file snapshot. It is not proof of a motive, a complete account history, or a recommendation to confront someone.

  • Check that your downloaded files contain the accounts you expected.
  • Keep a local baseline when you want to compare two export snapshots over time.
  • Use a broad change as one input to review your own posting goals—not as a judgment of a relationship.

If something looks surprising, request a newer export before drawing a conclusion. Accounts can change handles, files can be split, and activity can change after an export is generated.

Use the checker with context

Open the private checker when your export is ready. Before you do, read the complete methodology for file support, name handling, optional baselines, and the limits of the result.

PRACTICAL GUIDE

Prepare an Instagram export for a private comparison.

Use your own download, keep its related files together, and know exactly what the checker will—and will not—read.

Maintained by Unifolllow · Last reviewed November 8, 2026

Start with one complete download

Unifolllow compares two lists from the export you choose: accounts you were following and accounts that followed you. The clearest result comes from files in the same downloaded archive, because that archive represents one snapshot in time. Mixing a following file from today with followers from an older download can create differences that are only timing differences.

In Instagram’s Accounts Center, look for the option to download your information, choose the category covering followers and following, and use an all-time date range when that option is offered. Instagram changes labels and menu layout periodically, so use its current help text if the route on your device differs. Request only your own information and do not upload an export to a third-party service just to identify the two files.

Choose HTML or JSON—not both

Instagram downloads commonly contain both an HTML version that opens in a browser and a JSON version intended for structured data. Pick one format for a comparison. Unifolllow supports either:

  • followers_1.html, any additional followers_2.html / followers_3.html files, and following.html; or
  • followers_1.json, any additional numbered follower JSON files, and following.json.

The numbered follower files matter. A large export can be split into multiple follower files; leaving one out makes the follower count incomplete and can make the non-mutual list look larger than it is. The checker reads every selected file named followers_#.html or followers_#.json.

Find the files without changing them

After unzipping the archive, search inside it for followers_1 and following. In many exports they are under a connections or followers-and-following folder, but the surrounding folder names may vary. Select the actual files, not a screenshot, a CSV exported by another app, or the ZIP itself. Do not rename or edit the files; the tool checks their expected structure so it can give a useful error rather than silently making a guess.

Read the export health report first

After comparison, the export health report shows how many following accounts, follower accounts, and mutual accounts were read, along with the number currently in the non-mutual list. It is a quick completeness check, not a verdict on your account. If the totals look surprising, stop before acting on the list and confirm that every numbered follower file from the same archive was selected.

Use a saved baseline carefully

The “Save current list” button downloads a plain-text copy of the current non-mutual list. You may add that file during a later comparison. It does not turn the tool into an Instagram activity tracker: it only compares two local snapshots you supplied. With a baseline, Unifolllow still shows the full current list and adds counts for entries newly present and entries no longer present. That design avoids hiding a handle simply because it appeared in an older snapshot.

Keep the privacy promise practical

The comparison runs in your browser. Unifolllow does not ask for an Instagram password or account connection, and it does not transmit the selected files to a Unifolllow server. Still, exports can reveal relationship information. Store them as you would other personal downloads, avoid sending them in support messages, and delete local copies only when you are sure you no longer need them.

What a result can tell you

A result says that a handle appeared in the following file but not in the follower files from that snapshot. It cannot prove when someone changed their follow status, why they did so, or what Instagram currently shows after the export was generated. Names can change, accounts can be unavailable, and Instagram can change its export format. Treat the list as a starting point for a calm manual check, not as evidence about a person’s intent.

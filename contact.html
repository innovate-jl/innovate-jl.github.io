How Can We Help?

Troubleshooting

Most checker issues can be resolved without uploading any data anywhere:

  • File not appearing? Select both files from one export: followers_1 and following, in HTML or JSON.
  • Unexpected result? Use a newly requested export and choose the All time date range so the two files describe the same snapshot.
  • Need the full explanation? Read how Unifolllow calculates a result, including limitations of export snapshots.

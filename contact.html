CONTACT & SUPPORT

Get help without sharing your export.

Most file issues can be solved locally. Start with the guide that matches your situation, then send only the technical details needed for follow-up.

Before you contact us

For an unexpected result, use the troubleshooting guide. For file selection, use the export guide. These guides cover the most common causes: an incomplete numbered follower set, HTML and JSON files mixed together, and files taken from separate downloads.

What is safe and useful to include

  • Your browser and device type.
  • Whether you selected HTML or JSON files.
  • The exact filenames selected, without attaching the files.
  • The exact error message and the approximate date you requested the export.

What not to send

Never send an Instagram password, account token, export archive, account handle list, or screenshot that exposes personal relationship information. The checker is designed to keep those files on your device, and support should preserve that boundary.

Compatibility reports

If Instagram changes a filename or data structure, a short report with the format used, filenames, and error message helps us review compatibility without collecting your private data. The current supported formats are listed in compatibility and changes.

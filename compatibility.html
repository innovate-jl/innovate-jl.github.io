COMPATIBILITY

Supported export formats and product changes.

A transparent record of what the checker expects today, what it validates, and where its limits begin.

Maintained by Unifolllow · Last reviewed November 8, 2026

Supported file sets

The tool supports original Instagram follower-and-following exports in either HTML or JSON. Choose a single format for a single comparison.

  • HTML: following.html plus followers_1.html and any additional numbered follower files.
  • JSON: following.json plus followers_1.json and any additional numbered follower files.
  • Optional baseline: a local unifolllow-non-mutual-YYYY-MM-DD.txt file saved by this tool. Older known-following-YYYY-MM-DD.txt files remain readable.

What the checker validates

For JSON, the checker confirms that the follower file is a top-level list and that the following file has the expected following relationship list. For HTML, it reads Instagram profile links. In either format, it normalizes capitalization and an optional leading @ when comparing handles, removes duplicate handles, and produces a count of entries read. These checks are intended to catch mismatched or incomplete selections early; they cannot verify that Instagram’s export itself is complete or current.

What is intentionally unsupported

The checker does not accept a ZIP file, screenshots, CSV files created by another tool, copied text, a live Instagram profile, login credentials, or follower data from a different service. It does not connect to Instagram, call an Instagram API, follow profile links, or publish an ad unit next to the file controls. Keeping the supported surface narrow makes the privacy boundary understandable.

Known limits

An export is a point-in-time record. It cannot show the exact moment a person followed or unfollowed, their motive, a blocked or unavailable account’s status, or changes made after the download was prepared. Handle changes between snapshots can also make a legitimate account appear different. If Instagram changes file names or data structures, the checker may show a clear format error until the code and this page are updated.

How maintenance works

Compatibility claims are limited to the formats this page describes. When a reported export no longer matches them, the right next step is to examine the filenames and structure without collecting a user’s personal data, update the parser if appropriate, and revise this page with the behavior change. That is more useful than promising universal support for an export format that can change without notice.

TROUBLESHOOTING

Resolve an export issue without exposing your data.

Each check below is local: you do not need to send us your archive, login details, or a list of account handles.

Maintained by Unifolllow · Last reviewed November 8, 2026

The checker asks for followers and following files

Choose one matching format. For HTML, select following.html and every file named followers_#.html. For JSON, select following.json and every followers_#.json. The files must be selected together. A saved baseline text file is optional and is not a replacement for either required list.

“Select every followers file plus following”

This means the selected filenames do not form one supported set. Search the unzipped archive rather than selecting a parent folder. Do not mix HTML followers with JSON following. If there are several numbered follower files, include all of them. If an export uses a different name, save a copy of the folder structure for yourself and contact us with the filenames only—not the file contents.

“Not valid JSON” or “does not have the expected structure”

Pick the original file from Instagram’s download. JSON copied into a note, re-saved by a spreadsheet, or downloaded from another app can be altered even if it still ends in .json. The checker expects the follower list at the top level and the following list under Instagram’s relationships_following field. Re-download the archive if the original file does not work; formats can change.

Nothing happens after selecting files

After selection, press “Compare files.” Large downloads may take a moment to parse, but the page should remain responsive. If it does not, try one current browser with extensions temporarily disabled, then reload the page and select files again. Do not use private browsing if your browser blocks local file handling or downloads there.

The count is larger than expected

First check the health report. A very small follower count often means a numbered follower file was missed. Next, confirm the followers and following files came from the same archive. Finally, remember that this comparison only reflects the export snapshot; it cannot account for a follow change that happened after Instagram produced the files.

The count is smaller than expected

Handles are compared without capitalization and duplicate entries are removed, so a duplicated name does not increase the result. A user may also have changed their handle between exports. Refresh the data by requesting a new export and compare the complete file set from that download rather than attempting to edit a list by hand.

A saved baseline gives a surprising change summary

The saved file is a baseline for the previous current list, not an event log. The current list is always shown in full. “New since saved baseline” means a handle is in today’s current list but not in the saved list; “no longer on the current list” means the reverse. It does not identify the date or cause of any follow change.

Safe support request

If these steps do not resolve the issue, tell us your browser, whether you used HTML or JSON, the filenames selected, and the exact error message. Please do not attach an Instagram export, passwords, email address, account handles, or screenshots containing personal relationship data.
